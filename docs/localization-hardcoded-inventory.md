# Remaining localization inventory

The shared shell vocabulary is owned by `Localization/Shared`. The following visible strings remain feature-owned and are intentionally assigned to later localization stages.

| Owner | Primary surfaces | Delivery stage |
| --- | --- | --- |
| Agents | agent roster, profiles, briefs, chat, capabilities, access and configuration | Prompt 3 |
| Finance | overview, bills, invoices, payments, transactions, mailbox, reporting and settings | Prompt 4 |
| Sales | workspace, contacts, companies, opportunities, deal intelligence and activity | Prompt 5 |
| Support | inbox, case detail, drafts, refunds, knowledge gaps, memory and analytics | Prompt 6 |
| Shared formatting | dates, relative time, quantities, percentages, money and ranges | Prompt 7 |
| Error presentation | API problem details, stable error codes and retry guidance | Prompt 8 |
| Outbound communication | AI prompts, drafts, templates and recipient-language selection | Prompt 9 |

Machine values, route segments, logs, audit action codes, metrics, provider keys, persisted enums, correlation IDs and idempotency keys are invariant and must not be translated.
