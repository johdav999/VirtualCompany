## Fixture replay and measurements

The classifier is [WebRtcVad.NET 1.0.0](https://packages.nuget.org/packages/WebRtcVad.NET), a managed WebRTC GMM port with no native dependency, pinned for .NET 9. The [source](https://github.com/devnull/WebRtcVad.NET) declares MIT for the port and the WebRTC license for the imported algorithm. Restored package SHA-256: `B27892E8E17FEA50B57C926496ACF072E664C1D0A85E4F4B878C4FA056D02E21`. No model file or runtime download is required. Its public API gives a boolean classification, not calibrated confidence; diagnostics must not invent a probability.
The package has a small public maintenance footprint, so dependency review and real-device regression remain rollout risks despite the pinned checksum and successful local build.

24 kHz mono PCM is explicitly upsampled to 48 kHz in 10 ms frames. The real classifier is followed by a narrow-band rejection check and 240 ms onset confirmation. No volume-only cancellation fallback is used. A ready health check constructs the detector and classifies silence; failure marks the host unready. Browser failure pauses AI and leaves typed questions and human calling available; Teams bridge failure suspends voice and leaves typed controls.

Guided browser WebRTC uses self-hosted `@ricky0123/vad-web` 0.0.31, Silero v5, and `onnxruntime-web` 1.22.0. The detector reads the existing microphone `MediaStream`; it neither creates a second microphone capture nor forwards detection frames. Its 32 ms probability frames pass a narrow-band check and a 6-of-8 confirmation window. The pinned runtime/model assets and license notices are under `src/VirtualCompany.Web/wwwroot/lib/speech-vad/`; the selected WASM SHA-256 is `71AEF04959C5C1B6DE461B6538E2058E306610034A85AAD2742D0C7FD4533FE4`. Failure to load shows an actionable manual/transcription-mode warning rather than restoring raw provider-onset interruption. The browser package supplies probabilities; they are model outputs, not calibrated truth.
