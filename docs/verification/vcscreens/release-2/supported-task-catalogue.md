# Supported task-type catalogue

This is the current five-entry `TaskTypePolicyCatalogue`, not a promise that every registered capability supports automatic work. `/settings/agents/task-policies` uses the current company/agent policies. Preview is prospective: it creates no grant, queue, action or budget reservation; the owning Finance preview can record an audit. Apply requires an authorized current manager, exact current version and authority-bound hash. Policy activation alone proves no execution.

Non-Finance catalogue work binds exactly one company record, one current active agent and a current goal. Modes are `disabled`, `review`, `automatic`; 1–100 actions per UTC day, one action per task, expiry within 30 days and retained rationale are validated. Execution rechecks current company intent, tool/action/scope, original active actor and current role/responsibility, catalogue/policy version, expiry and budget. Reassignment does not transfer authority. Review is tied to actual material, never a blanket permission. Pause stops new admissions; already admitted work remains governed by its owning outcome. Uncertain admission cannot be retried under a new execution identity.

Finance budgets and grant windows are not summed with generic task actions. Its native eligible actions, freshness, currency/amount restrictions, reviewer rules and template limits remain authoritative. Use the Finance trigger/run workspace instead of treating catalogue visibility as a generic queue permission.

Not supported by generic task policy: customer delivery, Marketing publication, payments/money movement, ledger posting, final close/lock/statutory approval, credentials, permission/grant self-approval, unrestricted record loops, arbitrary tools or blind uncertain recovery. Separately governed owners may expose such operations with their own current authorization, approval, idempotency and outbox controls. Informational capability availability is not an execution grant.

Native prepared/reviewed/queued/executed/sent/provider-confirmed/settled stages remain distinct. Current automatic evidence uses deterministic AI analysis; live model quality, autonomous coordination, deployed tenant migrations, browser/native physical output and live provider/customer receipt are not certified by this catalogue.
