## Report definitions and reconciliation

`MarketingOperationalReportService` lives in Infrastructure.Sales and reads existing owning records; it does not introduce a second Marketing engine or stored daily snapshot. All queries explicitly scope company and are read-only. Calculation version is `marketing-operational-v1`; as-of is the current projection timestamp, not a reproducible historical snapshot.

Delivery includes current action states whose update time falls in `[fromUtc, toUtc)`. Prepared, awaiting approval, queued, dispatched, delivered, retry scheduled, failed and uncertain are distinct; dispatched means provider confirmation pending. Spend includes immutable campaign attribution-cost touches in the same period. It does not add observation cost snapshots. Currencies remain separate; unknown currency/cost evidence remains visible under a currency filter. Campaign budget is its recorded full-lifetime allocation, not an approved spend permission. Known spend minus budget is explicitly based only on recorded costs.

Leads include whole non-superseded `leads` observations contained in the selected UTC period and retrieved by as-of. Missing evidence, incompatible units and overlapping periods produce an unavailable total; retained source rows explain it. Attribution coverage is distinct in-period handoff contacts with an in-period attribution result. It does not establish causal success. Campaign portfolio includes records created before the period end; this is explicitly a current portfolio view.

Fixture reconciliation: recorded budget 100 SEK; known cost 120 SEK and 9 USD separately; one unknown-cost entry; recorded SEK difference 20; observed leads 4; no linked approved segment or complete attribution. A second campaign has no recorded budget, spend or outcomes. Reports and Today retain those gaps. No schema or migration is required: existing entities and string-valued approval targets store all added state.

CSV preparation rereads current authorized rows; download rereads again before the existing Blob download module. CSV contains company, filters, as-of, calculation, coverage, included records and UTC/source evidence; formula-leading text is escaped. Component tests prove refreshed payload handoff and denial after access revocation. The browser download event did not expose a saved file in 15 seconds; physical saved-file completion is unverified. See `uat.md` and `browser-checks.json` for the exact boundary.
