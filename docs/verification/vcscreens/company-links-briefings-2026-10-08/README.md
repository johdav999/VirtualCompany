## Root cause and evidence

The authorized Today API returned five agent updates, but the UI rendered only two. Those were the highest-ranked blockers, leaving the saved Sales and Support operating reviews invisible. `TodayAgentActivityQueryService.FromRun` read `Summary` alone; failed runs store their explanation in `FailureMessage`. Ben's actual persisted failure is `invalid_reasoning_result`: “The AI result cited evidence that was not supplied.” This is now shown instead of a generic state-change message. The actual failure remains blocked. Existing saved review summaries are displayed as dated, recorded agent results.

The prior CSS also hid task rationale, so Laura's mailbox failure explanation was unavailable in the visible card. Distinct rationale is now visible. Repeating the same summary as rationale is avoided.

Navigation coverage caught a shared routing defect: adding company context to a route containing a fragment placed query text after the fragment. `EnsureCompanyId` now uses the existing fragment-aware `WithQuery` helper. The Sales attention indicator can therefore target its actual section while retaining company and return context.

Final evidence: `after-browser.json`, `after-api-briefings.json`, desktop and destination PNGs, and `narrow-browser.json` with expanded `after-briefings-narrow.png`.
