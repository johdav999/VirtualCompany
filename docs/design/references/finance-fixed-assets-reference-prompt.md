# Finance fixed-assets reference prompt

Use case: ui-mockup

Asset type: visual target for the Virtual Company Blazor fixed-asset register workspace

Primary request: Create a polished desktop SaaS accounting workspace for managing fixed assets from capitalization through depreciation and disposal. The screen must immediately explain what is happening and what the accountant should do next.

Scene/backdrop: Virtual Company executive control-center application with a 240px left navigation, a spacious central Finance workspace, and a compact right-side Finance Manager insight panel.

Subject: The central workspace shows a header titled "Fixed assets" with a concise reconciliation status, four KPI cards for acquisition cost, accumulated depreciation, impairments, and net book value, then a dense-but-readable asset register table on the left and selected-asset detail on the right. Include visible workflow states for draft, active, impaired, and disposed assets; a depreciation run review card with period, proposed expense, exceptions, approval state, and primary "Review depreciation" action; and an evidence/timeline section linking acquisition, capitalization, depreciation, impairment, disposal, and journal records. The selected asset should expose asset class, placed-in-service date, useful life, residual value, method, custodian, location, dimensions, and ledger reconciliation. Include a clear empty/blocked exception treatment without raw storage identifiers.

Style/medium: High-fidelity modern enterprise SaaS UI mockup, clean and restrained, matching an accountant-grade control center rather than a marketing dashboard.

Composition/framing: Wide 16:9 desktop composition. Fixed left sidebar, central content with cards and split register/detail layout, narrow right insight panel. Dense sticky-header table, 12px rounded cards, 16px internal padding, strong visual hierarchy, responsive-friendly grouping.

Lighting/mood: Bright light-mode interface, calm, trustworthy, precise.

Color palette: Background #F7F9FC, white cards, primary #2563EB, success #16A34A, warning #F59E0B, danger #DC2626, dark slate text.

Text (verbatim): "Fixed assets", "Acquisition cost", "Accumulated depreciation", "Impairments", "Net book value", "Review depreciation", "Reconciled to ledger", "Needs review".

Constraints: Inter typography; headings at 600 weight; subtle shadows; readable table; plain-English labels; prominent safe next action; no fake charts; no provider internals; no raw GUIDs; include both normal and exception states in one coherent screen.

Avoid: decorative gradients, oversized charts, consumer-finance styling, cramped controls, unlabeled icons, dark mode, watermarks.
