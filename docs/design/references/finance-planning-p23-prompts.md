# Finance planning P23 reference prompts

Saved before reference generation and UI implementation. References are illustrative design inputs, never production data.

## Variance report
Create a polished desktop web application reference for Virtual Company Finance, 1440 by 1000. White/off-white canvas, dark navy typography, restrained blue buttons and teal accents, compact left navigation, generous card padding. Use clear English. Header: Finance / Reports, title Actual versus plan, subtitle Posted ledger evidence and selected planning versions. Filter row: January–March 2026, Budget version Approved plan, Forecast version April outlook, Currency SEK, Cost center All. Show a summary coverage strip, then a clean table with Month, Account, Actual, Budget, Variance, Forecast, Prior year. Display positive and negative signed amounts, a missing baseline as Unavailable, no mixed-currency total. Right panel: Laura · Finance, Explain the difference, Source evidence with journal and budget rows, Opening balances and cash timing excluded. Footer actions: Rolling forecast, Compare versions, Monthly review, Download selected rows. The result must feel like a usable real finance workspace, with accessible contrast and readable labels.

## Rolling forecast editor
Create a polished desktop web application reference for Virtual Company Finance using white/off-white, navy text, blue primary buttons, teal accents, left navigation, generous padded cards. Title Rolling forecast; subtitle Keep posted actuals and make future assumptions explicit. Show locked January–March actuals, future April–June editable account rows with explicit decimal amount and rationale, selected budget source and SEK currency. Inputs: Named version April outlook, Explanation Revenue timing updated. Distinct areas: Retained actuals; Future assumptions; Deterministic preview with actual, budget and forecast columns. No scenario or cash projection totals. Right panel Laura · Finance: No journal or payment actions, source coverage, preview status. Actions Preview assumptions, Save named version; saved history list with immutable revisions and reopen action. Never suggest statutory approval. Show an explanation for unavailable actual coverage.

## Version comparison
Create a polished desktop web application reference for Virtual Company Finance using the same white/off-white canvas, navy text, blue and teal accents and generous card spacing. Title Compare forecast versions. Two explicit saved version selectors: March outlook and April outlook, currency SEK, cost center All. Show an aligned table of monthly account values: Actual retained, Earlier forecast, Later forecast, Change, Explanation. Unmatched rows display Unavailable rather than zero. Show saved source dates and a clear note that later live records do not change retained values. Right panel Laura · Finance with assumptions and provenance, source drilldown, monthly review link. Accessible readable table, no mixed-currency total, no technical IDs in ordinary UI.
