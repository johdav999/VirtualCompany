# Statement import center reference prompt

Use case: ui-mockup
Asset type: Visual implementation reference for the Virtual Company Blazor Finance statement-import page
Primary request: Create a high-fidelity, production-ready SaaS screen for a governed bank statement import center where finance teams upload, preview, validate, and resume ISO 20022 CAMT or CSV statement imports.
Scene/backdrop: Existing Virtual Company desktop application shell with a fixed 240px white left navigation, Finance selected, a pale #F7F9FC workspace, and a narrow contextual Laura finance-manager card.
Subject: The main content is headed "Statement imports" with the subtitle "Preview and validate bank files before they affect your transactions." Include Finance secondary navigation with Transactions active and Statement imports selected as an operational sub-route.
Style/medium: Calm, trustworthy, human-readable modern B2B SaaS UI; Inter-like typography; white cards with soft #E5E7EB borders, 14–16px radii, subtle shadows, restrained blue #2563EB accents, orange warnings, red errors, and green completion states.
Composition/framing: 1440x1000 desktop screenshot. Header and a top-right "New import" action. Below, a two-column operational layout: left 64% upload/preview workspace, right 36% validation and Laura guidance. The upload card contains a drag-and-drop file area, mapped bank account selector, optional CSV mapping profile selector, and a primary "Preview file" button. Under it, show four compact summary cards for rows, accepted, duplicates, and issues, followed by a dense readable preview table with status, date, reference, counterparty, amount, currency, and issue columns. The right column contains a clear validation report grouped by blocking errors and warnings, a control-total reconciliation panel, and a Laura card explaining that preview is not an import. At the bottom, include a resumable import-history card with file name, format/version, progress, state, updated time, and Resume/View actions.
Text (verbatim): "FINANCE", "Statement imports", "Preview and validate bank files before they affect your transactions.", "New import", "Drop a CAMT or CSV file here", "Preview file", "Rows", "Accepted", "Duplicates", "Issues", "Validation report", "Control totals", "Preview is not an import", "Import history", "Resume", "Complete import".
Constraints: Make error, duplicate, partial/resumable, empty, and completion states visually distinguishable without implying that a preview is committed. Avoid provider logos, raw enum values, tenant jargon, technical XML internals, decorative charts, gradients, dark futuristic styling, or mock production balances. Use the reference only as a design target; the shipped UI will be built with native components and CSS.
Avoid: illegible micro-text, overfilled cards, generic analytics dashboard composition, invented bank branding, false success claims, watermark.
