# Finance Today reference prompt

Use case: ui-mockup. Create a high-fidelity desktop screenshot of Virtual Company Finance Today, following docs/design.md. Light #F7F9FC canvas, 240px white navigation sidebar, blue #2563EB accents, dark #0F172A text, quiet borders, white rounded cards and generous spacing. Existing Overview role and Today/Monthly controls remain above the content. Heading 'Finance today', subtitle 'Review cash, obligations and the next permitted action'. Four compact cards: Available cash (with source timestamp and explicit missing-evidence state), Overdue receivables, Due supplier bills, Reconciliation exceptions. Every monetary value includes its currency; do not combine currencies. Two-column action area: left due-obligation list with invoice/bill identity, due date, remaining amount and Review action; right Laura, Finance Manager, with named avatar, source coverage and clear 'Review cash forecast' action. Bottom compact links for Receivables aging, Payables aging, Cash forecast, Payment review, Bank reconciliation, Accounting close, Income statement and Balance sheet. Include a subdued notice: 'Payment requests remain pending until provider settlement is confirmed.' Small inset mobile layout stacks the same cards and actions. Illustrative values only, no technical internals, no decorative charts.
