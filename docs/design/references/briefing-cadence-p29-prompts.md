# P29 visual reference brief

Built-in ImageGen, following `docs/design.md`; reference only, never a UI bitmap.

Generate one wide, crisp SaaS product reference board with three clearly separated views of Virtual Company: Schedule, Preview, Absence routing. Inter type, pale #F7F9FC canvas, white 12px-radius panels, #2563EB actions, restrained semantic status chips. Existing 240px sidebar includes Company, Work, Finance, Sales, Marketing, Support. No decorative charts.

Schedule view: heading Briefing preferences, company selector, role selector Sales / CEO / Marketing / Finance / Support; timezone Europe/Stockholm, working hours and quiet period inputs, grouped routine updates and unchanged-content switches. Seven compact editable cadence rows: Morning, End of day, Shift handover, Weekly, Monthly, Quarterly review, Annual review, each with enabled toggle, local time and applicable weekday/day/month controls. A distinct urgent escalation section with its own quiet-hour policy. Primary Save preferences.

Preview view: next delivery local time and UTC offset, freshness timestamp, recipient and cadence, real work rows with priority, due date, source status, current-work and retained-source links. Empty and access-restricted states described clearly. Delivery audit rows distinguish Queued, Sent, Suppressed, Failed, Uncertain, Retry.

Absence routing view: start/end local dates, eligible delegate select, accountable fallback select, clear text Routing grants no record access or approval authority. Readable narrow layout stacking cards and rows, all inputs have visible labels. Reference combines these three states, with consistent spacing and typography.
