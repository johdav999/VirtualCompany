# Slide-card visual reference

Generated with the built-in ImageGen tool; reference only, not a replacement for PowerPoint images.

Use case: ui-mockup. Create a high-fidelity desktop reference screenshot for Virtual Company's existing Presentation preset PowerPoint editor. Professional business SaaS, Inter typography, white cards, #F7F9FC background, #2563EB accents, dark navy body text, subtle borders, 12px card corners, 16px spacing. Focus on the processed-slides panel, not the full app shell. Heading 'Processed slides', count '3 slides'. Two equal-width slide cards side by side with a third below. Each card shows a full 16:9 PowerPoint slide image first, uncropped; example cream-colored business slide with blue heading 'Wellheld' and a restrained business software illustration. Under image a compact title row 'Slide 1 · Overview'. Immediately under title exactly two tabs 'Spoken dialogue' (active blue underline) and 'Speaker notes'. Left card active Spoken dialogue panel shows plain script text 'Welcome to Wellheld. Your company, well held.' plus muted 'Prepared narration · Marin' and text action 'Edit in Script & audio'. Right card active Speaker notes panel shows an editable textarea, 'Save notes' blue button, 'Discard changes' secondary button, and amber 'Audio needs update' badge. Clearly separate on-slide imagery, spoken words, and author notes. The slide image must dominate upper half of each card, no giant block of extracted text pretending to be an image. Clean real-world UI, no gradients, no decorative avatars, no icons necessary. Keep sidebar and surrounding page out of frame so card details are legible. Reference only; do not use mockup as actual application asset.
