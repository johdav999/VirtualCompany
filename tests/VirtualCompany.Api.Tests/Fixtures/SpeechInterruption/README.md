# Speech interruption test corpus

`stop-alex-en.wav` and `stanna-alex-sv.wav` are synthetic, non-customer 24 kHz mono PCM16 utterances generated locally with Windows Speech Synthesizer (Microsoft David Desktop en-US and Microsoft Bengt sv-SE). The text is authored for this test. No microphone recordings, customer data, or transcripts from meetings are retained. These fixtures verify the classifier, not real-device echo cancellation or background-speech intent.
